# Dot SVG Maker

ウェブベースのドット絵エディターです。ブラウザ上でドット絵を描き、SVG・PNG・WebP 形式でダウンロードできます。

🎨 **[GitHub Pages で公開中](https://oqzl.github.io/Dot-SVG-Maker/)**

## 機能

- **グリッドキャンバス** — サイズ変更可能（最大 128×128）
- **描画ツール** — 鉛筆 / 消しゴム / 塗りつぶし / スポイト
- **カラーパレット** — 色の追加・管理
- **エクスポート**
  - SVG（ベクター、ファイルサイズ最適化済み）
  - PNG（スケール倍率指定可）
  - WebP（スケール倍率指定可）
- **ズーム** — 4〜64px/セル
- **元に戻す / やり直し**（最大 50 ステップ）
- **背景色 / 透明背景**
- **グリッド表示切替**
- **タッチ操作対応**
- **キーボードショートカット**
  - `P` — 鉛筆
  - `E` — 消しゴム
  - `F` — 塗りつぶし
  - `I` — スポイト
  - `Ctrl+Z` — 元に戻す
  - `Ctrl+Y` / `Ctrl+Shift+Z` — やり直し

## ローカルで実行

```bash
# 静的ファイルのみなのでそのまま開けます
open index.html
```
